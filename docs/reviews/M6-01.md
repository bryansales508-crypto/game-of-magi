**2. WorldClockService: OK apart from F1.**
- `DayStart` and `DayLength` are set once, at Start or on first use through `ensureStarted`. `DayPaused` is present only while paused. There is no Heartbeat and no Lighting access on the server.
- `ClockTimeAt` (`WorldClockService.luau:62-69`) is pure, reading only frozen Config constants. The day part covers `DaySeconds` from DawnHour to DuskHour, the night part covers `NightSeconds`, and it wraps (Luau `%` is non-negative). This matches decision 4. I hand-checked it: 0 → 6, D → 18, D/2 → 12, D+N/2 → 0, L → 6.
- `.time` is registered through `DevService.Register`, and `Dispatch` checks `IsDev` on the server (`DevService.luau:639`).
- `.time speed` rejects nil, NaN, ≤0 and >1000, so there is no divide by zero and no negative length. `.time <h>` rejects anything outside 0-24 and NaN.
- Pause, resume and speed all keep the current hour, and `SetHour` while paused moves the frozen hour.
- The self-test puts the clock back where it found it (speed, hour, paused).

**3. CollisionService: OK.**
