## Findings

1. **MEDIUM** `GripController/init.luau:141-148, 179-189` (`poseVictim`): the victim pose is very likely invisible. `Modules/Ragdoll/init.luau:148-149` sets every Motor6D except Root/RootJoint to `Enabled = false` while the player is knocked, so changing the shoulder `C0` (or playing a looping Action4 track) does nothing on a ragdolled body. Gripper pose is fine (RootJoint stays enabled). Plain words: the knocked-out player's arms will not actually go "out"; only the gripper visibly changes. Fix: pose the victim another way (leave the ragdoll alone, or drop the victim pose until Bryan's animation exists) and have the playtester confirm in M9-I.
2. **MEDIUM** `init.luau:628-632`: release is only sent from `UserInputService.InputEnded` and the prompt's `PromptButtonHoldEnded`. There is no `WindowFocusReleased` handler (spec item 1), and with `HoldDuration = 0` the prompt's hold-end event is not guaranteed to fire for touch/gamepad. Alt-tab while holding G leaves `holding = true`; the server then relies on its own timeout/`moved away`. Plain words: if the window loses focus mid-grip the grip is not let go. Fix: also call `releaseGrip()` on `UserInputService.WindowFocusReleased` and on `InputEnded` for the gamepad button.
3. **LOW** `init.luau:597-600` (`onLocalCharacter`): on respawn `holding` is cleared without sending `GripStop`. Harmless today because `GripService` ends the grip when a party dies or is gone, but it breaks the "release always sent" rule. Fire `GripStop` first if `holding` was true.
4. **LOW** `init.luau:342-357, 504-516`: `hideScreens()` never resets `dimFrame`/vignette transparency, so the next grip on the same client starts from the previous grip's last darkness and tweens down from there (a brief flash of dark/red). Reset transparency to 1 (and bar fill to 0) in `hideScreens`. Also each server tick (4/s) creates up to 5 new tweens; reuse or set directly.
5. **LOW** `init.luau:61-66, 573-588`: reasons are shown raw, so internal wording such as "death scene" or "a party is gone" appears in chat as "The grip broke: death scene." Map those to plain lines, or skip them. Also `postSystemLine` is a third copy of the same helper (BountyController:59, DevController:313); share it.
