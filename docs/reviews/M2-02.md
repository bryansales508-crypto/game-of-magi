- A `RukhSceneDone` from a player who isn't dying finds no listener, so it does nothing. The 30 s timeout fires even when the client never answers.
- On a first load, DataService sets `TimePassed` from 0 to now before `Loaded` fires (`DataService.luau:162`), so a new character does not age by decades.
