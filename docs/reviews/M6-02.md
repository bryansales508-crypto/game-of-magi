## Server agreement
- Attributes: client reads `DayStart`, `DayLength`, `DayPaused` on Workspace, exactly the names the server sets. OK.
- Clock rule: client `hourAt`/`cycle` (LightingController.luau:311-348) equals server `ClockTimeAt` (WorldClockService.luau:40-47). Day part = DawnHour..DuskHour over `DaySeconds`, night over `NightSeconds`, both scaled by `DayLength / (Day+Night)` (which is how `.time speed` works), `DayPaused` wins and is mapped back to a cycle position consistently. Verified algebraically; a paused hour of 0, 6, 18 and 24 all land on the right side.
- The client no longer sends `MiscRemotes.Footstep` and no longer reads `IntFold`; it reads the `Running` attribute that `MovementService` sets (MovementService.luau:246). The server deletions in M6-01 do not break anything the client still uses.
