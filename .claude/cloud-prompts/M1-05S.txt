## Contract with the client (the client-builder builds the dev panel and F8 overlay in M1-05C; do not build client code)
- Net remotes you add to `Shared/Remotes.luau`:
  - `DevCommand` (Event, client -> server, one string max 200 chars, rate 5 per 1 s): a command line exactly as it would be typed in chat.
  - `DevReply` (Event, server -> client, one string): the human-readable result of a command.
  - `DevState` (Event, server -> client, one table): a snapshot for the overlay, sent to each dev on request (`DevCommand ".state"`) and automatically every 1 s to any dev whose `DevState` subscription is on (`DevCommand ".watch on|off"`).
- The snapshot table shape (keep it flat and stable; the client renders keys in this order): `{ name, userId, joinState, age, magoi, rank, goldRukh, blackRukh, epithet, bounty, copper, silver, gold, walkSpeed, health, maxHealth, position = {x, y, z}, saveScope, freshSave, timeScale, sessionSeconds }`. Missing systems (rank title isn't built until M4) send a placeholder string like "n/a".

## Commands (all start with `.`; `.cmd` lists them with one-line help; unknown command replies with help; every command replies with what changed, old -> new)
- `.state [player]`: sends the snapshot to the caller and logs it as one readable multi-line block in Output (this is what the playtester reads instead of clicking around).
- `.watch on|off`: overlay stream on/off.
- `.coins <copper> [silver] [gold] [player]`, `.coins+ ...`: set or add. `.age <years> [player]`, `.age+ <n>`, `.magoi <n>`, `.magoi+ <n>`, `.rukh <gold> <black>` (sets the two tallies), `.bounty <n>`, `.epithet <text>`. All write through the DataService table (the legacy bridge mirrors them to the old Values), never to the Values directly.
- `.tp <city>`: teleports the caller's character to a spawn point. Cities are the children of `Workspace.MAP.Spawns` (cloud has no Workspace, so resolve at runtime: match `<city>` case-insensitively against child names, allowing the `Spawn` suffix, e.g. `.tp qarzin` -> `QarzinSpawn`). `.cities` lists what exists. The known cities: Qarzin, Rathole, Saleh, Sahraqin, Ain Jamala, Illegal Port, Jaddatys Hut.
- `.timescale <n>`: sets `Config.Debug.TimeScale` at runtime. Config is frozen, so expose it through `DevService.GetTimeScale()` and a `DevService.TimeScaleChanged` signal, and note in a comment that later milestones (aging, day/night) read it from here.
- `.fresh`: `DataService.Wipe(player)` then re-run the join placement (kick-free; the old scripts rebuild from the bridge). `.save`: `DataService.Save(player)`.
- `[player]` arguments default to the caller; match by display name or username prefix, case-insensitive; ambiguous -> reply with the candidates.
