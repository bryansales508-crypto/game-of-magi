## Contract with the client (M3-05/M3-06; do not build client code)
- Remotes (add): `Attack()` rate 6/s, `Block(on: boolean)` rate 4/s. The client NEVER reports what it hit.
- `CombatEvent` kinds you emit (to all clients): `Swing {character, setName, moveIndex}`, `Hit {attacker, target, moveIndex, finisher, knockback}`, `Blocked {target, attacker}`, `Parried {attacker, target}`, `BlockBroken {target}`, `Knocked {target, by}`, `Recovered {target}`.
- Attributes: `ComboStep` (number), `NextAttackAt` (server clock), `Blocking` (from StatusService), `WeaponSet` (string, "Fist" for everyone now; M5 sets others).

## What to build: `src/ServerScriptService/Server/Services/CombatService.luau` (+ small helpers under `CombatService/` if needed)
1. **Attack:** on `Attack()` from an owner (or `CombatService.Attack(character)` from NpcService): reject if dead, stunned, knocked, true-stunned, blocking, or before `NextAttackAt`; pick the move: combo step advances if within the previous move's `comboWindow`, else back to 1; emit `Swing`; schedule the hit at `hitTime`; at hit time (still valid?) do a **server-side hit check**: a spherecast/blockcast from the attacker's torso along its look vector of length `move.range` and radius `move.radius` (use `ReplicatedFirst.ShapecastHitbox` if it works server-side, otherwise `workspace:Spherecast`/`GetPartBoundsInRadius` with a filter), collect the FIRST other combatant whose character model owns the hit part (walk up to the Model with a Humanoid, so a weapon or pack finds its character: AUDIT M3/P2); then apply the hit (below). Set `NextAttackAt = now + windup + recovery` and `ComboStep`.
2. **Applying a hit:** if the target is `Blocking` and facing the attacker (dot product of look vectors < 0, i.e. attacker in front): if within its parry window (`Block.Value == 1`) and parry not on cooldown -> `Parried`: stun the attacker `Block.breakStun/2`, `StatusService.Apply(attacker, "Stun")`, emit; else -> `Blocked`: `HealthService.SpendBlock(target, Block.drainPerHit)`; if it returns false (block empty) -> `BlockBroken`: remove Block, apply `TrueStun` for `Block.breakStun`, emit. **A blocker never takes damage, stun, slow or knockback while the block holds (AUDIT M1).** Otherwise: `HealthService.TakeDamage(target, damage, attacker)`, `StatusService.Apply(target, "Hit", Stagger.hitStun)` and `"Stun"`, `MovementService.SetModifier(target, "Hit", 0.5)` for the stun, knockback impulse (finisher uses its own value), emit `Hit`. If health reaches 0 -> **knockout** instead of death: health to 1, `StatusService.Apply(target, "Knocked", Knockout.getUpSeconds, {by = attackerName})`; on expiry `Recovered` with health set to `Knockout.healthOnGetUp` x max. (Whether a knocked player can be killed comes with bounties in M5; for now they just get up.)
3. **Block:** `Block(true)`: apply `Block` with value 1 for `parryWindow` then 0 (StatusService data), parry cooldown per combatant (AUDIT H5: no duplicate markers, no endless parries), `MovementService.SetModifier(character, "Block", blockSpeedMult)`; `Block(false)` or any stun/knock removes it. Block HP is `HealthService` block (M2-03); fix AUDIT M2 (parry over-cap) by never adding block above max.
