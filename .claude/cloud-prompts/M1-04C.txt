## The contract with the server (the server-builder builds the other half in M1-04S; do not build it)
- The server sets a string attribute **`JoinState`** on the Player: `"Loading"` (save loading, character not placed yet) -> `"Loaded"` (save loaded, character spawned and placed at the Qarzin spawn) -> `"Ready"` (the server got the client's ready signal; old systems may now run). It is set again on every respawn (back to `"Loading"` then `"Loaded"`).

- No fixed timers anywhere. The client waits on the attribute (`player:GetAttributeChangedSignal("JoinState")`), the server waits on the remote.
