## Contract with the client (M2-05 builds `RukhController`; do not build client code)
- Remote `HeartAttack` (server -> client, `age: number`, `fatal: boolean`): sent on every online birthday from age 60. Non-fatal: the client shows a one-second heartbeat/red pulse and it passes. Fatal: the client shows the heavier version and then the return-to-the-Rukh scene.
- Remote `RukhSceneDone` (client -> server, no args, rate 2 per 60 s): the client sends it when the scene ends. The server then starts the new life. If it doesn't arrive within `Config.Aging.SceneTimeout` (30 s), the server starts the new life anyway.
- Player attributes: `Age` (years), `Lives`, `Dying` (boolean, true from the fatal roll until the new life spawns).
